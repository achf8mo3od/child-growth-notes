# 警惕一氧化碳中毒！记住这几条“保命法则”

> 更新时间：2026-09-16 (UTC+8)

冬季是一氧化碳中毒的高发期，每年都有因中毒而死亡的病例。一氧化碳中毒可防可控，为避免悲剧，我们将从专业角度带您认识一下这个“隐形的杀手”——一氧化碳中毒，也就是我们常说的“煤气中毒”。

**一、一氧化碳从哪里来？**

一氧化碳是一种无色、无味、无刺激性的气体，主要来自含碳物质的不完全燃烧。平常感觉不到它的存在，这正是它最危险的地方。在我们日常生活中，主要来源有：

1.燃气热水器：这是导致洗澡时中毒的“头号元凶”。特别是直排式热水器，它将燃烧产生的废气直接排放在室内，极其危险。

2.取暖陷阱：煤炉、炭火盆和燃气取暖器。在门窗紧闭的卧室、出租屋内使用煤炉、炭火盆取暖，煤炭燃烧时，如果通风不畅，会产生高浓度的一氧化碳。使用没有安装外排烟道的燃气取暖器，同样会将废气直接排入室内。

3. 汽车尾气：在密闭的车库内开着汽车发动机（无论是开空调还是取暖），尾气中的一氧化碳会迅速积聚，造成车内人员中毒。汽车怠速状态下，排气管被积雪、淤泥堵塞，尾气也可能通过车厢缝隙倒灌入车内。

4.其他潜在风险：在通风不良的室内、地下室或帐篷里使用小型发电机、燃油机，以及火锅店里使用炭火铜锅，如果通风系统不佳，也存在风险。

**二、如何预防？——记住几条“保命法则”**

预防一氧化碳中毒，核心就是 “通风” 和 “安全” 四个字。

法则一：确保通风，永远的第一要务

 使用燃气时：务必打开抽油烟机或排风扇，至少保持一扇窗户敞开，形成空气对流。

洗澡时：浴室门窗不要完全密闭，留一条缝隙，洗澡时间不宜过长。

取暖时：绝对不要在卧室内使用煤炉、炭火盆。使用合格的取暖设备，并保持定期通风。

法则二：正确安装和定期检修燃气设备

 燃气热水器：必须由专业人员安装，并确保是强排式。绝对禁止将任何类型的热水器安装在浴室或通风不良的室内。排烟管必须完全伸出窗外。

法则三：安全使用汽车

切勿在密闭的车库内长时间开启发动机。车辆停驶时，如果长时间开空调，最好将车窗留出缝隙。定期检查排气管是否通畅。

法则四：安装一氧化碳报警器

这是最有效、最直接的保命装置。它就像家里的烟雾报警器一样，一旦检测到空气中一氧化碳浓度超标，会立即发出尖锐的警报声。

**三、发生一氧化碳中毒如何急救？ **

如果发现家人或朋友出现头晕、头痛、恶心、呕吐、乏力等症状，且处于可能产生一氧化碳的环境，应立刻按以下步骤行动：

1. 开门开窗，切断源头：立即打开所有门窗通风，迅速关闭燃气开关、熄灭炭火等。

2. 迅速转移：立即将中毒者转移到通风良好、空气新鲜的地方，并注意保暖。

3. 保持呼吸通畅：解开中毒者的衣领、腰带，让其平卧，头偏向一侧，防止呕吐物吸入气管导致窒息。

4. 立即求救：第一时间拨打120急救电话，清楚说明地址和“怀疑一氧化碳中毒”。

5. 判断情况，必要时心肺复苏：如果患者已无呼吸、心跳，应立即进行心肺复苏，直到医护人员到达。

6. 争取高压氧治疗：到达医院后，向医生说明情况。对于中重度中毒，高压氧舱是首选治疗方法。

**四、什么是高压氧治疗？**

对于一氧化碳中毒，尤其是中重度中毒及有高危因素的患者，高压氧是根本性的、不可替代的治疗手段。其作用机理远超普通人的“吸氧”概念：

1. 迅速纠正缺氧：在高压环境下，物理溶解于血液中的氧气量大幅增加，可以不依赖血红蛋白直接向组织供氧，立即解除细胞的“窒息”状态。

2. 加速一氧化碳清除：高压氧能加快一氧化碳从血红蛋白上“置换”下来的速度，迅速降低碳氧血红蛋白浓度，改善缺氧。

3. 减轻脑水肿、降低颅内压：这是抢救生命、保护脑功能的关键。

4. 抑制免疫炎症风暴：减轻再灌注损伤和氧化应激，从根源上阻断对神经系统的“二次打击”。

5. 促进神经修复：刺激神经干细胞活性和髓鞘再生，为受损的神经系统修复创造环境。
