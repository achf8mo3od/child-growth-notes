# ICU科普小知识：“卒”不及防，“识”不宜迟

> 更新时间：2026-09-17 (UTC+8)

**“卒”不及防，“识”不宜迟——冬季中风防治指南**

随着冬季来临，气温骤降，脑卒中（俗称“中风”）也进入了高发期。尤其对于中老年人，寒冷的天气潜藏着健康危机。为什么冬季卒中易发？我们又该如何识别与应对？这份科普指南为您一一解答。

**认识卒中：什么是脑卒中？**

脑卒中，是大脑血管突然破裂或阻塞，导致血液供应中断、脑组织受损的急性脑血管疾病。主要分为两类：

**缺血性脑卒中（占70%—80%）**

脑血管堵塞，导致脑部供血不足。

**出血性脑卒中（占20%—30%）**

脑血管破裂，血液渗入脑组织造成损伤。

**冬季为何成为卒中“高危期”？**

寒冷天气通过以下机制增加卒中风险：

**血管收缩：**低温使血管收缩，若本身已有血管狭窄，脑供血会进一步减少。

**血液黏稠：**寒冷时血流减慢，血液更易黏稠淤滞。

**血压波动：**冬季血压容易升高，增加血管负担。

在“血管收缩”与“血液黏稠”的双重影响下，缺血性卒中发病风险显著上升。

**这些人要格外警惕：卒中危险因素**

若您有以下情况，需特别重视预防：

**疾病因素：**高血压、糖尿病、高血脂、心脏病（尤其房颤）、颈动脉狭窄。

**生活习惯：**吸烟、饮酒、肥胖、缺乏运动。

**家族史：**有脑卒中家族史，或本人曾发生过卒中。

**快速识别中风：“1-2-0”三步法**

**看一张脸**

面部不对称，嘴角歪斜。

**查两只胳膊**

单侧手臂无力、无法抬起。

**（聆）听说话**

口齿不清、表达困难。

**只要出现其中一种症状，立即拨打120！**

争分夺秒送往具备卒中救治能力的医院。

**突发中风，现场急救怎么做？**

**保持镇静：沉着应对，不慌张。**

**立即呼救：**拨打急救电话，清晰说明地址和症状。

**平稳放置：**让患者平卧，头偏向一侧，防止呕吐窒息。

**保持呼吸通畅：**松开衣领、腰带，勿喂水喂药。

**记录时间：**尽可能记下发病时间，为医生抢救提供关键信息。

**预防卒中，从生活细节做起**

**1. 控制“三高”**

定期监测血压、血糖、血脂，遵医嘱规律服药。

**2. 健康生活**

**戒烟限酒：**烟草显著增加卒中风险；饮酒应适量。

**均衡饮食：**多蔬果、全谷物，低盐、低脂、低胆固醇。

**坚持运动：**每周≥150分钟中等强度有氧运动（如快走、游泳）。

**控制体重：**避免肥胖，减少血管负担。

**3. 定期体检**

尤其高危人群，应定期进行心脑血管相关检查，早发现、早干预。

**寒冷虽至，健康可守。**
提高警惕，识别征兆，积极预防，就能大幅降低卒中风险。为自己和家人的健康，多一份关注，多一份安心。
