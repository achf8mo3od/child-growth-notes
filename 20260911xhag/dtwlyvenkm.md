# 妊娠与弓形虫感染

> 更新时间：2026-09-11 (UTC+8)

现在大多数家庭会在家里养猫来陪伴自己，平时养着是挺好，但到了准妈妈怀孕的时候，要不要把猫送出去，就成了一个大难题。送出去吧，舍不得；不送出去，又怕对胎儿不太好。其实大家对孕期养猫的担忧，主要是来源于猫咪可能带有的一种寄生虫—弓形虫。

弓形虫广泛分布于世界各地，是一种严重危害人类健康的人兽共患寄生虫。弓形虫因滋养体似弓形而得名，感染人体后可引起弓形虫病。全球约1/3的人口都曾感染过弓形虫，但多为隐性感染或原虫携带，没有症状。而对免疫功能低下的人群或者孕妇而言，则可能引起严重的并发症甚至死亡，并且可能会经胎盘传染给胎儿，引起胎儿和新生儿的疾病。

猫科动物是弓形虫的最终宿主，虫卵可随猫的粪便排出，但只有首次感染弓形虫的猫咪会在感染后的2周内传播虫卵。其他哺乳动物（牛羊狗等）为其中间宿主，这些动物肉类可能含有弓形虫包囊。弓形虫感染一般不会由人传人，但母亲有可能经胎盘传给正在发育中的宝宝。

**人是怎么感染上弓形虫的呢？**

人感染弓形虫的途径很多，主要有以下几个途径：

1. 首次感染的猫咪可能会排泄出弓形虫的卵囊（类似虫卵），如果被人食用， 则可能会感染弓形虫。吃了受卵囊污染的水果蔬菜、生奶，接触过受污染的土壤并吃下了肚等等，都有可能感染弓形虫；

2. 受感染的动物肉类（牛羊狗等）中存在弓形虫包囊，人吃了此类未煮熟的生肉，是感染的另一主要途径；

3. 接受已受感染的器官移植，或输入已受感染的血液；

4. 经胎盘的垂直传播。

**弓形虫感染对胎儿及新生儿的影响**

妇女在妊娠期感染弓形虫后，可无任何临床症状，也可能出现流产、死胎、畸形等一系列改变。存活婴儿典型的先天性弓形虫病表现包括脑积水、小头畸形、脑钙化、视网膜脉络膜炎（弓形虫病四联症），以及婴儿发育障碍、中枢神经系统受累（脑瘫、癫痫、智力低下、精神症状）。先天性弓形虫病患儿多于出生后 1个月内表现出症状，出生后无症状及未经治疗的先天性弓形虫病患儿可出现远期后遗症，主要为精神运动障碍及视、听力损害。新生儿感染一般较先天感染的症状轻，但表现复杂，以淋巴结和内脏器官症状为多见，全身各个部位的淋巴结都可被侵犯，引起淋巴结炎，还可表现为脑膜炎、心肌炎、肺炎等。

**弓形虫感染的筛查与诊断**

目前，弓形虫病的筛查、诊断的方法主要包括血清学抗体检测、病原学检测和分子生物学方法。血清学抗体检测是目前筛查弓形虫感染最方便、最常用的方法，孕前体检中有一项TORCH的检查，就是针对弓形虫、风疹病毒、巨细胞病毒、单纯疱疹病毒等多种疾病的初步筛查。为了避免弓形虫对胎儿产生危害，如果女性家里养猫、狗等宠物，建议在怀孕前三个月最好做一次弓形虫抗体定量检查。如果血清弓形虫IgG、 IgM检测均为阴性，提示无弓形虫感染，但有获得初次感染危险，建议孕期定期复查。如果血清弓形虫IgG检测为阳性、IgM检测为阴性，表示受检者既往感染过弓形虫，已产生了相应抗体，若无临床症状，不需要再检测和治疗。如果初次检测血清弓形虫IgG为阴性或阳性、IgM为阳性，需要在15~30 天后再次复查受检者血清抗体滴度，同时结合其他检查指标和询问接触史，排除假阳性。如果确诊弓形虫急性感染者应避孕，接受治疗后再计划妊娠。对高度怀疑近期感染弓形虫的孕妇以及超声检查提示有胎儿畸形者及免疫功能受损的孕妇，可对其羊水进行 PCR 扩增技术检测，有效检测胎儿弓形虫感染情况。孕期进行彩色多普勒检查（B超）及磁共振成像（MRI）检查在诊断严重的先天性弓形虫感染中也有重要意义。

**日常生活中如何避免感染弓形虫？**

目前尚无法通过接种疫苗来预防弓形虫感染，我们只有提高对弓形虫病的认识来降低感染率。简单来说要做到以下几点;

1、注意饮食卫生，鱼、肉、蛋、奶食用时要充分煮熟；切勿食用生的或未煮熟的肉类，处理生肉后要及时洗手，并清洗餐具和砧板，避免交叉污染其他食物，不要饮用未经杀菌消毒的任何动物奶。

  2、不要和饲养的猫、狗太过于亲密接触，避免在亲昵中不小心受到伤害。接触宠物后要记得及时洗手，不要直接触碰宠物的粪便，可以戴手套处理。

  3、饲养的猫、狗应喂熟食或成品粮食，不与流浪猫、狗接触。

**弓形虫感染的治疗**

绝大多数免疫功能正常者，弓形虫感染后不需治疗可自行康复，如果感染影响到患者的眼部、心脏或脑，可考虑联合药物治疗。对于孕妇、免疫系统功能低下或患有艾滋病、癌症等疾病者的弓形虫感染，需要积极治疗
