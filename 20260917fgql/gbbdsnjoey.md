# 【妇产科普】母乳不够吃？试试中医强推的5碗下奶神汤

> 更新时间：2026-09-17 (UTC+8)

针对产后乳汁分泌不足的问题，食疗是备受推崇的天然调理方式。中医典籍《本草纲目》中曾记载：“穿山甲、王不留，妇人食了乳长流”，临床实践中也常选用这两味中药代茶饮、煮粥或煲汤，以促进乳汁分泌。以下推荐几款实用食疗方，助力妈妈们轻松实现母乳喂养：
1. 通草鲫鱼汤

配方：鲫鱼1条，通草30克，生姜1片。

做法：鲫鱼处理后与通草、生姜加水同煮，小火慢炖至汤色浓白，加盐、味精调味即可。

功效：通络下乳，适合乳腺不通畅的妈妈。

2. 黄芪当归母鸡汤

配方：老母鸡1只，黄芪30克，当归15克。

做法：老母鸡切块，与黄芪、当归一同炖煮至肉质酥烂。

功效：补气养血，适用于气血虚弱型乳汁不足。

3. 猪蹄汤/粥

配方：猪蹄2只，大米100克，姜末、葱末、食盐适量。

做法：猪蹄炖煮至软烂，取汤煮粥或直接食用；若煮粥，粥熟后加入调味料拌匀即可。

功效：通经下乳，可搭配通草增强效果，每日2顿，连服3-5天。

4. 王不留行黄酒鸡汤

配方：老母鸡1只、王不留行10克（布包）、黄酒适量、生姜2片。

做法：老母鸡与药材、黄酒、生姜同炖，煮至鸡肉酥烂后饮汤。

功效：活血通经、下乳消痈，适合乳腺淤堵的妈妈。
